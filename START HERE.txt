Open this folder, then:

1. Double-click  Setup EfficiencyFinder.command   (first time only)
2. If macOS asks whether to open it, click Open
3. Wait until setup finishes (a few minutes the first time)

After that, open the app by double-clicking  EfficiencyFinder.app
You can drag EfficiencyFinder.app to the Dock for one-click launch.

You may see a one-line message about zsh when Terminal opens. That is harmless.

If the app says it is not set up, run Setup EfficiencyFinder.command once more,
then use EfficiencyFinder.app after that.
